# 压缩动物 · Compressed Animals

> 牛、羊、猪、鸡的一、二、三级压缩变体：血量与体型暴涨、掉落成倍、要用压缩面包繁殖，村民还会偶尔叫出压缩铁傀儡。
>
> Tier I–III compressed cows, sheep, pigs and chickens with huge health, multiplied drops, compressed-bread breeding and a rare compressed iron golem.

**Minecraft 1.21.1 · Fabric · 作者 yzt**

## 简介

原版的四种农场动物在世界里被压缩版本取代：越大的个体血越厚、掉落越多，三级个体甚至会追着你还手。想继续养它们，就得先做出压缩面包。

## 特性

- 4 种动物 × 3 级 = 12 个新生物；只替换这四种的自然生成（65% 一级 / 25% 二级 / 10% 三级），马、骡等其他生物刷新完全不受影响
- 基础生命 270 / 7290 / 72900，每只额外随机 ±25 / ±520 / ±1000
- 体型 1.5× / 2.5× / 4.0×；三级额外获得 5–20 攻击力，并会主动近战反击
- 掉落按等级成倍复制原版掉落，并额外掉压缩肉：一级 30% 掉一级压缩肉；二级 30% 掉一级 + 5% 掉二级；三级必掉一级与二级
- 繁殖：一级吃一级压缩面包，二级以上吃二级压缩面包，子代与父母同级
- 村民召唤铁傀儡时有 10% 概率改为召唤压缩铁傀儡（3600 生命 / 90 攻击 / 掉 8–16 铁块，无刷怪蛋、无法建造）
- 依赖「压缩食物」，压缩肉与压缩面包都来自那里

## 安装

1. 安装 Minecraft 1.21.1 与 Fabric Loader（≥ 0.16.14）
2. 安装依赖：Fabric API（必需）、压缩食物（必需）
3. 把 `compressed-animals-1.0.0.jar` 放进 `mods` 文件夹

## English

The four vanilla farm animals are replaced in the world by compressed versions. Bigger individuals have far more health and drop far more; tier III ones will even turn around and fight back. To keep breeding them you first need compressed bread.

- 4 animals × 3 tiers = 12 new mobs. Only these four vanilla spawns are replaced (65% tier I / 25% tier II / 10% tier III); horses, mules and everything else spawn exactly as before
- Base health 270 / 7290 / 72900, plus a per-mob random roll of ±25 / ±520 / ±1000
- Scale 1.5× / 2.5× / 4.0×. Tier III also rolls 5–20 attack damage and fights back with a melee goal
- Drops multiply the vanilla loot by tier and add compressed meat: tier I 30% for tier I meat; tier II 30% tier I and 5% tier II; tier III always drops both
- Breeding: tier I animals eat tier I compressed bread, tier II and III eat tier II compressed bread, and the child keeps the parent tier
- Villagers have a 10% chance to summon a compressed iron golem instead of a normal one (3600 HP, 90 attack, drops 8–16 iron blocks; no spawn egg and no build pattern)
- Requires Compressed Foods — both the meat drops and the breeding bread come from it

### Installation

1. Minecraft 1.21.1 with Fabric Loader (≥ 0.16.14)
2. Dependencies: Fabric API (required), Compressed Foods (required)
3. Drop `compressed-animals-1.0.0.jar` into your `mods` folder
